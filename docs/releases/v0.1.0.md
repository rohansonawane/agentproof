# AgentProof v0.1.0 Technical Preview

AgentProof v0.1.0 is the first public technical preview of a stateful simulation and fault-injection testing framework for tool-using AI agents.

The core idea is simple: test what the agent does to the simulated world, not only what it says.

## Included

- Isolated simulated worlds with state, tools, effects, events, traces, virtual time, and installed faults.
- Explicit effect ledger for side effects that actually commit.
- Deterministic invariants over final world state, trace, and effects.
- `timeout_after_commit` support for retry-after-success-hidden-by-timeout failures.
- Stable mutations for timeouts, errors, latency, rate limits, malformed responses, missing fields, stale state, permission denial, duplicate user requests, delayed events, and duplicate events.
- Replay artifacts for deterministic native failures.
- CLI support for CI gating, JSON reports, and JUnit reports.
- Native Python adapter.
- Optional OpenAI Agents SDK adapter using real SDK `FunctionTool` objects.
- Optional LangChain/LangGraph adapter using real `StructuredTool`, `StateGraph`, and `ToolNode` APIs.
- Pytest plugin marker registration.
- Runnable README quickstart.
- Real external LangChain booking-app smoke test.

## Security Notes

AgentProof is a testing framework, not a sandbox or production runtime safety layer.

Use virtual tools, fakes, local simulators, or isolated staging services. Do not point AgentProof tests directly at production refund, payment, email, deployment, account-management, or file-deletion APIs.

Live model tests are opt-in and may send prompts, tool schemas, and relevant context to the configured provider.

## Current Limits

- API stability is technical-preview level.
- Live LLM behavior is not exactly replayable.
- Secret redaction is best effort, not comprehensive data-loss prevention.
- `reorder_tool_results` is intentionally unsupported in this MVP.
- There is no hosted dashboard, SaaS runner, runtime policy engine, or production permissions layer.

## Install From GitHub Release

Download the wheel from the release assets and install it with:

```bash
python -m pip install agentproof-0.1.0-py3-none-any.whl
```

PyPI publication is intentionally separate and requires an explicitly configured Trusted Publisher.
