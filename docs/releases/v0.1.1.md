# AgentProof v0.1.1 Package-Name Readiness

AgentProof v0.1.1 publishes the project to PyPI under the distribution name `agentproof-sim`.

The Python import package and CLI remain unchanged:

```bash
python -m pip install agentproof-sim
agentproof mutations
```

```python
import agentproof
```

## Why The Name Changed

Live PyPI checks on 2026-09-03 showed that both `agentproof` and `agentproof-ai` are already occupied by unrelated projects. The `agentproof-sim` distribution name keeps the AgentProof brand while making the simulator/testing purpose clear.

## Included

- Distribution metadata moved from `agentproof` to `agentproof-sim`.
- Version bumped to `0.1.1`.
- Package author set to Rohan Sonawane.
- README, publishing docs, adapter error messages, and smoke-test commands updated for `agentproof-sim`.
- Clean-wheel smoke checks now select the wheel from the current `pyproject.toml` distribution name.
- Release-hardening now cleans generated build artifacts before building.
- README quickstart extraction now selects the executable refund example by content.
